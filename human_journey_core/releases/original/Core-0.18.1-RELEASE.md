- Mechanics: isolated wrap/safety package, native chunk/storage/movement/packet mixins, server lifecycle and registered owned tickets. Existing FULL-only upgraded NBT proofs precede bounded destination loading. Missing/incomplete/corrupt/outside data is rejected before generation; non-FULL placeholder saves are refused. Full groups are held/clipped, never detached/recreated. Failed placement does not move part of the group. Direct position bypass recovery uses a validated whole-group anchor or nearest same-side existing recovery; unrecoverable legacy positions stop the server rather than guess.
- Limits: 4 pending groups, 16 members/group, 25 target/81 dependency chunks/job, 200-tick deadline; 32 active/1024 queued I/O and 4096 cached proofs/map, 10-second read deadline; temporary 241-tick nonpersistent LOADING tickets. Shared own-ticket reference counts protect concurrent jobs and do not remove other systems' tickets. Success/failure/cancel/stop releases ownership. Runtime native loading upgrades are distinguished from failed dependencies so valid requests are not globally cancelled.
- Diagnostics: `/hj wrap status`, permission2. LOADING/HELD/FAILED report `crossed=false`; only a committed normal crossing reports CROSSED/`crossed=true`. Recovery reports HELD. Successful diagnostics include committed source, desired canonical target, actual arrival, group and inward adjustment. Failed destinations have an explicit reason. Logging is bounded per group. No per-tick spam.
