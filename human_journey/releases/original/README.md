# Original Human Journey releases

All nine user-supplied archives are preserved byte for byte. SHA256SUMS.txt records original SHA-256 hashes. Versions: 0.1, 0.2, 0.3.1–0.3.6 and 0.3.8. No 0.3.7 was supplied.

These are historical snapshots, not deployment instructions. Only the 0.3.8 working source is validated and built by the current development workflow. No historical ZIP is installed in Minecraft.

The editable source imports v0.3.8 gameplay unchanged, adds human_journey.version to pack.mcmeta and relocates five bundled text notes to docs/imported/v0.3.8. The verified test build therefore differs from the archived original ZIP.
